A simple Python program that recognizes facial patterns and records names and the exact time of recognition in a CSV file.

Steps required to use the program:
Have a webcam
Have CMake installed on your system

1. Create a virtual environment and activate it (not strictly necessary)
2. Install the required libraries:
pip install -r requirements.txt

Purpose of the `Images` folder: This is where you will place the images of the people you want the system to recognize.

Purpose of the `attendance.csv` file: This is where the name and time of recognition will be recorded.
